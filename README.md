# Structural robustness of the global crude petroleum trade network (2017, 2019, 2020)

**Reproducibility and revision materials for a manuscript submitted to *Discover Sustainability*.** The country-level trade networks cover crude petroleum, HS 2709, with nominal bilateral values in **US dollars**, for three author-selected years: 2017, 2019 and 2020. This is a descriptive cross-sectional network comparison; it is **not** an estimator of the causal effect of sanctions or COVID-19.

## Run the numerical analysis

Python 3.10 or newer is recommended. From the root of the repository:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python code/reproduce_analysis.py
```

The script imports canonical annual directed weighted GEXF networks from `networks/`, independently cross-checks every supplied GEXF edge against the accompanying clean CSV edge list in `data/processed/`, and writes recalculated centralities, model fits, networks, robustness checks, null comparisons, community partitions and figures to `reproduced/`. Analysis seeds are specified in the source. NetworkX and dependency versions are recorded in `reproduced/RUN_METADATA.json`.

To regenerate Gephi-compatible colored/positioned GEXF files from the existing canonical GEXF, if needed:

```bash
python code/style_gephi.py
```

**Gephi:** choose *File → Open* for `networks/oil_trade_2017_directed_weighted.gexf` and the analogous 2019 and 2020 files. These are **editable directed weighted GEXF documents** with node attributes, community assignments and persisted visualization positions. A `.gephi` workspace is not generated by these Python routines; save a native Gephi workspace after opening a file in Gephi.

## What the data support

The directed edge convention is `source=exporter`, `target=importer`, and edge `weight=trade_value_usd`. Degree and shortest-path centralities use the directed binary topology unless otherwise specified. In- and out-strength are weighted by USD. HITS scores use the USD-weighted adjacency matrix. Harmonic outward centrality is defined on directed reachability. **Undirected weighted community detection sums the two directed dollar values** for reciprocal country pairs. Louvain is run at resolution 1, seed 46 for plotted groups, and 20 alternative seeds for sensitivity.

The largest weakly connected component after removal is expressed as a fraction **of surviving nodes**, not the original nodes. Targeted deletion removes vertices in a fixed descending baseline total-degree order; random removal averages over 70 permutations with seed 20261102. Degree-preserving rewiring comparisons use 25 graphs per year. These simulated interventions do **not** estimate disrupted barrels, delivery delays, rerouting capacity, or trade recovery.

## Data provenance caveat and open science policy

The authors identify the source as [OEC's crude petroleum (HS 2709) trade profile](https://oec.world/en/profile/hs/crude-petroleum). Country-level exports and imports were reportedly downloaded separately and compiled into one annual file. The originally documented reconciliation/duplicate-mirror-report policy was not sufficiently detailed to rebuild every edge from the OEC site. The `2019.zip` supplied during revision contains **96 country-specific `importers-of-crude-petroleum` workbooks** (94 distinct country names) and one aggregate workbook. Audit extraction found **1,343 source country/partner records**, of which **1,268** match a directed country pair in the consolidated 2019 graph. Only **261** dollar values match exactly and **372** match within 1% (including exact matches); **75** source pairs were absent. This is recorded record-for-record in `data/audit/raw_2019_crosswalk.csv`. We have **not** silently replaced or interpolated the consolidated values.

Jurisdiction label repairs are logged in `data/audit/data_cleaning_audit.csv`. The node name `Chinese` in the 2019 consolidated graph (35 edges) has an unresolved identification and **is not merged with China**. The source data and displayed results are therefore subject to these unresolved data-provenance limits. Authors should confirm the source's time of retrieval, mirror statistics policy, licensing, and unresolved names before publication.

To rerun the optional 2019 source-file audit locally, use an **independently and lawfully obtained** copy of the ZIP archive (not bundled here):

```bash
python code/audit_raw_2019.py --raw-archive "/your/path/2019.zip"
```

This requires `lxml` as specified in `requirements.txt` and writes audit files to `reproduced/raw2019_audit/`.

## Word, EndNote and cross-references

Word captions are stored as dynamic `SEQ` fields, and in-text figure/table references as `REF` fields pointing to named bookmarks. In Microsoft Word use **Ctrl+A → F9** to refresh field results after editing. The authors' original EndNote-connected library was not included; the manuscript contains `ADDIN EN.CITE`-style field payloads for citations and the `references/EndNote_Import_Verified.ris` file provides source records. **An EndNote user must import/check these records in their own library, run EndNote Cite While You Write → Update Citations and Bibliography, and verify that the citations resolve as genuine working EndNote references.** The local software-dependent linkage has not been tested here.
